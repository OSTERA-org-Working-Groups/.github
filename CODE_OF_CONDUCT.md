# Code of Conduct

<!-- BEGIN STANDARD TEXT -->

All participants are expected to follow the OSTERA [Code of Conduct](https://github.com/OSTERA-org-Working-Groups/.github/blob/main/CODE_OF_CONDUCT.md).

<!-- END STANDARD TEXT -->

## Reporting a Concern

To report conduct that you believe violates the Code of Conduct, please contact the Secretariat at [secretariat@ostera.org](mailto:secretariat@ostera.org). Please do not report or discuss conduct concerns in any public issue or public forum.
