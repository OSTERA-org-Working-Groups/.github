# Security Policy

## Reporting a Security Issue

If you believe that an OSTERA specification, draft, or any code in these repositories contains a security issue, please report it privately. Do not open a public issue.

Please use the GitHub private vulnerability reporting mechanism by clicking on the "Report a vulnerability" button on the Security tab for that repository. 

In addition, you can send your report to [security@ostera.org](mailto:security@ostera.org), including:

* The document or repository affected, including its version
* A description of the issue and its possible impact
* Any steps or examples that demonstrate the issue

## What to Expect

OSTERA is run by volunteers. We will acknowledge your report as soon as we can, keep you informed as the issue is reviewed, and credit you when a fix is published, unless you ask us not to.
