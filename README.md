# OSTERA Working Groups: Shared Repository Files

This repository holds the default community files for every repository in the OSTERA-org-Working-Groups organization. It does not contain Working Group material. Each Working Group has its own repository.

## How These Files Are Used

GitHub uses the files in this repository as defaults. When a Working Group repository does not have its own copy of one of these files, GitHub shows the copy from this repository instead. Changing a file here therefore changes it for every Working Group repository that relies on the default.

| File | Purpose |
| --- | --- |
| `CONTRIBUTING.md` | How to comment on drafts and propose changes |
| `CODE_OF_CONDUCT.md` | Points to the official OSTERA Code of Conduct |
| `SECURITY.md` | How to report a security issue privately |
| `SUPPORT.md` | Where to ask questions |
| `PULL_REQUEST_TEMPLATE.md` | Default text for new pull requests |
| `.github/ISSUE_TEMPLATE/` | Issue templates and contact links |
| `profile/README.md` | The organization landing page at `github.com/OSTERA-org-Working-Groups` |

## Overriding a Default

A Working Group that needs different rules can add its own copy of a file to its repository. That copy then replaces the default for that repository only. Please discuss any override with the OSTERA Secretariat first, so that Working Groups stay consistent. Otherwise, the Secretariat may remove the override.

Two exceptions apply:

* **LICENSE** is never inherited. Each repository must contain its own.
* **GitHub Actions workflows** are never inherited. They are provided through the wg-template repository.

## Related Repositories

* [wg-template](https://github.com/OSTERA-org-Working-Groups/wg-template/): the template used to create new Working Group repositories
* [wg-tools](https://github.com/OSTERA-org-Working-Groups/wg-tools/): the commands, checks, and website build shared by every Working Group repository, with the documentation of their folders and the [Chair Guide](https://github.com/OSTERA-org-Working-Groups/wg-tools/blob/v1/docs/chair-guide/README.md)
* [OSTERA-org/publications](https://github.com/OSTERA-org/publications/): approved OSTERA documents, published at [pub.ostera.org](https://pub.ostera.org/)

## Participating

Participation is open to OSTERA members. However, anyone may comment on a draft during its Public Review. See [How to Participate](https://wg.ostera.org/participate/), and read the [Contributing Guidelines](https://github.com/OSTERA-org-Working-Groups/.github/blob/main/CONTRIBUTING.md) before you open an issue or a pull request.

## Public Repositories

These repositories are public. Materials that are confidential to OSTERA members **MUST NOT** be stored in them, or anywhere else on GitHub. They **MUST** instead be stored in the [OSTERA Portal](https://member.ostera.org/).

## Publications

Approved documents are published at [pub.ostera.org](https://pub.ostera.org/), not in the Working Group repositories.

## Policies

The official OSTERA policies, including the IPR and Copyright Policy, the Working Methods, and the Code of Conduct, are published at [ostera.org/policies/](https://ostera.org/policies/).

## Intellectual Property

Anything you submit to OSTERA, such as an issue, a pull request, a comment, or an email, is a contribution under the [OSTERA IPR and Copyright Policy](https://ostera.org/policies/), and by submitting it you agree to that policy. Do not submit anything you do not have the right to contribute.

If you have knowledge of intellectual property rights, including patents, copyrights, trademarks, and service marks, for software or text, the use of which may be required to implement or publish any of the work items being considered, please disclose it by following the instructions at [ostera.org/ipr/](https://ostera.org/ipr/) or contact the Secretariat at [secretariat@ostera.org](mailto:secretariat@ostera.org).

## Code of Conduct

All participants are expected to follow the OSTERA [Code of Conduct](https://github.com/OSTERA-org-Working-Groups/.github/blob/main/CODE_OF_CONDUCT.md).

## Questions

For general questions about OSTERA, visit [OSTERA.org](https://ostera.org/) or contact the Secretariat at [secretariat@ostera.org](mailto:secretariat@ostera.org).
